Theoretical Failure Explanations

1. Data Errors (Corrupted Inputs & Labels)

Null values disrupt feature representations; extreme out-of-distribution values distort gradients; mislabeled instances confuse decision boundaries.

2. Algorithmic Bias (Fairness Violation)

When unprivileged demographic groups suffer lower approval rates, the model violates the US EEOC 80% Four-Fifths rule, creating discriminatory disparate impact.

3. Covariate & Concept Drift

Macroeconomic shifts alter input feature distributions (Covariate Shift) or changing consumer dynamics shift $P(Y|X)$ (Concept Drift), rendering existing models obsolete.
